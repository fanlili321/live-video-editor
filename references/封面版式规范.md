# 封面版式规范

> 2026-08-18 制定
> 起因：467 期三条竖版封面的标题全部压在人物脸上（人工复核每条第①点）
> 适用：`05-工具/batch.py` 生成封面、`05-工具/covercheck` 验收

---

## 一、问题是什么

`cover make` 默认把标题块**垂直居中**。横版的人物在右下角，居中尚可；
竖版的人物在画面中部，居中的标题正好落在脸上。

实测（竖版，未修正前）：

```
标题三行 ink：y = 676..843 / 880..1039 / 1049..1328
人物顶            y = 795
```

**第一行就已经越过人物顶，第二、三行整个压在人像上。**

排查时顺带发现**横版也有同样的隐患**，只是没被指出来：
`增量资金和存量资金` 这行的右端压进人物轮廓 **43px**，
`多长时间一轮呢` 距人物只剩 **29px**。

> 根因是同一个：**版式参数是按某一条标题标定的，而标题长短每条都不同。**
> 只要标题变长，居中的文字就会往人物那边扩张。固定坐标解决不了变长的文本。

---

## 二、模板几何（实测）

用 `05-工具/covercheck` 的同一套检测逻辑量出，可复现。

### 竖版 1080×1920

| 项 | 值 |
|---|---|
| 人物顶（黄色描边最高点） | **y = 795**（占画布高 41.4%） |
| 照片带 | y = 795 .. 1681 |
| 标题可用净空 | y = 0 .. 795 |

人物横向占 x = 182..1079，**几乎横跨整个画面宽度**。
所以竖版的约束是**纵向的**：标题必须整体位于 y=795 之上，没有靠左右躲避的余地。

### 横版 1920×1080

| 项 | 值 |
|---|---|
| 人物顶 | y = 465 |
| 人物横向 | x = 1297 .. 1919 |
| 人物左边界（第 1 行标题所在高度 y≈335..500） | x ≈ 1680 |
| 人物左边界（第 2 行标题所在高度 y≈580..750） | x ≈ 1580 |

人物只占右侧，**左边界随高度变化**（越往下人物越宽）。
所以横版的约束是**横向且逐行不同的**：标题可以和人物同高，但右端必须让开。

## 三、版式规则

### 3.1 竖版：标题锚定在人物之上，不居中

| 参数 | 值 | 依据 |
|---|---|---|
| 行数 | **固定 3 行** | 4 行在 em=165 下会顶出画布上沿 |
| 字号 em | 165 | 沿用既有标定 |
| 行距 pitch | 206（= 1.25 em） | 沿用既有标定 |
| **末行 ink 底锚点** | **y = 755** | 人物顶 795 − 安全距离 40 |
| 单行 ink 宽上限 | 980 px | 画布宽 1080 − 左右各 50 边距 |

实现：`cover make … --inkbottom 755`。
锚定后实测三行 ink 为 y=186..344 / 392..550 / 598..754，**净空 41px**。

### 3.2 横版：逐行限宽

| 参数 | 值 | 依据 |
|---|---|---|
| 行数 | 固定 2 行 | 沿用既有版式 |
| 字号 em | 171（会自动缩小，见 3.3） | 沿用既有标定 |
| 行距 pitch | 251（= 1.47 em） | 沿用既有标定 |
| 垂直位置 | 标题块垂直居中 | 沿用既有版式 |
| **第 1 行 ink 宽上限** | **1350 px** | 2 ×(人物左界 1680 − 安全 40 − 画布中心 960) |
| **第 2 行 ink 宽上限** | **1150 px** | 2 ×(人物左界 1580 − 安全 40 − 画布中心 960) |

### 3.3 超长标题：按比例缩字号，不改版式

标题长短不可控，因此**宽度上限是硬约束，字号是可变量**。

```
需要宽度 = ink系数(该行) × em
若 需要宽度 > 该行上限：em ← em × 上限 / 需要宽度（取所有行里最严的那个比例）
行距 pitch 同比例缩小，保持版式比例不变
```

**ink 系数**：每汉字 **1.0 em**，数字与拉丁字母 **0.55 em**。
> 实测思源黑体 Heavy 每汉字约 0.995 em。这里取 1.0 **是刻意偏保守的**——
> 系数估低会算出偏大的字号，直接压到人物身上；估高只是字略小一点。
> 第一版用 0.985，结果两条封面各差 30px 和 38px 没达标。

467 期实际触发情况：

| 条目 | 断行 | 字号 |
|---|---|---|
| 02 横版 | 星级指标 / 适合哪些指数 | 171（未触发） |
| 03 横版 | 增量资金和存量资金 / 投法有何不同 | **171 → 151.4** |
| 07 横版 | A股的牛熊市 / 多长时间一轮呢 | **171 → 164.3** |
| 竖版三条 | 均 3 行 | 165（未触发） |

### 3.4 安全距离

统一取 **40 px**（相对 1080 短边约 3.7%）。
低于 40px 视为不合格；低于 0 即已重叠。

## 四、验收：`covercheck`

```bash
05-工具/covercheck <成品封面.png> <模板.png> [安全距离，默认40]
```

**做法**：用「成品封面 − 模板」的像素差分提取标题。
成品 = 模板 + 标题，差分出来的就正好是标题，不受背景干扰。

> 一开始是按颜色找米黄色文字，但**人物的皮肤和高光也是米黄色系**，
> 检测结果里混进了脸和衬衫。差分法没有这个问题。

**输出**：逐行 ink 范围、行宽占比、与人物的间距，以及总体结论。
不合格时退出码为 1，可直接接进批处理做卡口。

当前 467 期三条六张全部通过：

```
02 竖版 ✅   02 横版 ✅
03 竖版 ✅   03 横版 ✅
07 竖版 ✅   07 横版 ✅
```

## 五、换模板时要重做的事

模板一旦更换（新的人物照、新的构图），本文所有坐标全部作废，需重新标定：

1. 用 `covercheck` 里的同一套黄色描边检测，量出人物顶和逐行左边界
2. 竖版：`cover_inkbottom` = 人物顶 − 40
3. 横版：各行 `cover_maxink` = 2 ×(该行高度处人物左界 − 40 − 画布中心 x)
4. 参数写进 `batch.py` 的 `SPEC`
5. 拿最长和最短的两条标题各生成一次，跑 `covercheck` 验收

> **不要靠目视确认。** 467 期横版那 43px 的重叠，肉眼看上去只是「有点挤」，
> 不量就发现不了；而它已经切到人物轮廓里了。
