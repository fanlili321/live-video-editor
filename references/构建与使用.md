# 工具：构建与使用

本目录是整条管线的全部源码。本机没有 ffmpeg 也没有 Homebrew，所有音视频处理都用 macOS 自带的
Swift + AVFoundation / Vision / CoreText / Speech 实现，**零第三方依赖**。

## 一、构建

```bash
cd 05-工具
for f in vtool rms measure facescan rendertext cover render band \
         scenescan slidematch covercheck colorbox patchfill; do
  swiftc -O $f.swift -o $f
done
swiftc -O measure_crop.swift -o crop     # 唯一一个源码名与产物名不同的
```

**二进制没有入库**，换机器/换账号后必须先跑这一段。全部重建约 1 分钟。
自检：`ls` 一遍，上面 13 个 + `crop` 共 14 个可执行文件都在，才算齐。

语音识别必须打成 .app（否则被 TCC 直接杀掉，见「踩坑」）：

```bash
mkdir -p ASRTest.app/Contents/MacOS
swiftc -O asr.swift -o ASRTest.app/Contents/MacOS/ASRTest
cp ASRTest-Info.plist ASRTest.app/Contents/Info.plist
codesign --force --deep -s - ASRTest.app
```

Python 侧只用到标准库 + `jieba`（系统 python3.8 已装）。

## 二、各工具职责

| 工具 | 职责 |
|---|---|
| `vtool` | `info` 探测 / `frame` 抽帧 / `trim` passthrough 无损切片 |
| `rms` | 输出音频 RMS 包络，用于静音间隙与起音点检测 |
| `measure` | `fullframe` 全分辨率抽帧 / `face` 人脸框 / `bright`·`dark` 文字 bbox 与行带 / `scanrow` 像素扫线 / `inkarea` 墨量占比 |
| `crop` | 裁剪放大出图，用于目视比对 |
| `band` | 逐行亮度扫描，找非黑区块（标定竖版版式用） |
| `facescan` | 全片人脸采样取中位数，算裁剪框 |
| `rendertext` | 按规格渲染一行字幕，用于和样片比对标定 |
| `cover` | `fill` 反推干净封面模板 / `make` 在模板上排版标题 |
| `render` | 主渲染器：裁剪 + 烧字幕 + 视频内标题 + 封面片头 + 分段拼接 + H.264 编码 |
| `ASRTest.app` | 本地词级时间戳识别（Apple Speech，离线免费） |
| `asrwin.sh` | 对指定时间窗跑一次识别，输出带绝对时间的词表（排查用） |
| `asr_all.py` | 全片分块识别 + 重叠 + 自动补洞，产出完整词表 JSON |
| `make_srt.py` | 富文本脚本 → 清洗 → 与词表对齐 → 删除线剪切区间 → 断行 → 起音吸附 → 字幕 JSON |
| `qc_subs.py` | 字幕质检，分 `[错]`（必须修，阻断渲染）/ `[疑]`（人工看）两级 |
| **`batch.py`** | **整期批量驱动：定位→切片→裁剪框→识别→字幕→质检→封面→渲染。日常只跑这一个** |
| `scenescan` | 场景切换检测（标定 PPT 段落用） |
| `slidematch` | 拿手机录屏逐帧比对幻灯片，自动求出翻页时间 |
| `covercheck` | 封面验收：差分提取标题 ink，比对与人物轮廓的间距，不合格退出码 1 |
| `dropcheck.py` | 漏词检测：拿本机逐字 ASR 反查妙记顺滑掉的口语词，分类聚合后只报需人判断的 |
| `colorbox` / `patchfill` | 取色、补图，标定模板时用 |

## 三、`render` 参数

```
--src <切片>            --out <成片.mp4>
--canvas W,H            输出画布，默认 1920,1080
--band x,y,w,h          视频画面落在画布上的位置（top-origin），默认铺满
--crop x,y,w,h          从源画面裁剪的区域（源画面像素，top-origin）
--subs <字幕.json>      --cover <封面.png>   --coverdur 0.12
--keep a-b,c-d,...      保留区间（源片秒），用于剪掉删除线段落
--fps 25                --bitrate 10000000
--font / --em / --stroke / --bottom          字幕字体、字号、外描边、底边距
--sub-fill r,g,b                             字幕填充色
--shadow-alpha / --shadow-blur / --shadow-dx / --shadow-dy   给了 alpha 就切到「实色 + 半透明阴影」样式
--title "行1|行2|行3"   --title-em / --title-pitch / --title-inkbottom / --title-rgb / --title-font
--preview-at <成片秒> --preview-out <png>    只出一帧预览，不编码视频（调样式用，2 秒出图）
```

## 四、踩坑（复现必看）

| # | 坑 | 解法 |
|---|---|---|
| 1 | CLI 直接调 `SFSpeechRecognizer` 立即 SIGABRT | 必须打成带 `NSSpeechRecognitionUsageDescription` 的 .app |
| 2 | 直接 exec `App.app/Contents/MacOS/App` 照样崩 | 必须 **`open -n ./App.app --args …`**；不带 `-n` 会静默不启动 |
| 3 | 授权拿到了但识别永远无回调 | `recognitionTask` 回调走主队列，不能用 semaphore 阻塞主线程，要用 `RunLoop.current.run(mode:before:)` |
| 4 | 长音频/长停顿会丢弃前段 | 见项目文档「ASR 分块吞头」：分块重叠 + 自动补洞 |
| 5 | 直接喂 .mov 识别不稳 | 先用 `AVAssetExportPresetAppleM4A` 抽成 m4a |
| 6 | TCC 授权按 bundle id 记 | 固定 bundle id（当前 `local.asrtest`），换了要重新弹窗 |
| 7 | `CGColor(red:green:blue:)` 画上去颜色会偏 | 会经历色彩空间转换。必须用 `CGColor(colorSpace: CGColorSpaceCreateDeviceRGB(), components:)` |
| 8 | `CTLineDraw` 画出来是黑的 | CoreText 用属性串里的 `.foregroundColor`，**不认** `ctx.setFillColor`。颜色必须写进 `NSAttributedString` |
| 9 | 用 CoreText 负 `strokeWidth` 做描边会把字身吃掉 | 描边必须两遍绘制：先 stroke（线宽 = 2×外扩）后 fill |
| 10 | `lark-cli drive +download` 只接受相对路径 | `cd` 到目标目录再下载；5.7GB 大文件容易被服务端中断，人工下载更稳 |


## 四、日常只需要这两条命令

```bash
cd 05-工具
python3 batch.py --config ../02-过程/<期次>/期次配置.json --rows 2,3,7
python3 batch.py --config ../02-过程/<期次>/期次配置.json --rows 2,3,7 --stage render
```

其余工具都是 `batch.py` 内部调用，或排查/标定时才手动使用。
参数与前置条件见 `../项目文档.md` 第七节。
