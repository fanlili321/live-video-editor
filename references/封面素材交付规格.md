# 封面素材交付规格（给设计侧）

> 2026-08-12
> 用途：把「每条标题单独出一张成品封面」改成「一套可复用素材 + 程序按标题自动排版」。
> 目标：每期 10–15 条封面全自动生成，风格与现有 GPT 成品一致。

---

## 一、为什么不能直接用成品图反推

现有成品图（如「A500、A50指数，为什么会诞生」）把文字**烧进**了纸条纹理里，抹不掉：

| 问题 | 实测 |
|---|---|
| 纸条长度是按文字裁的 | 红条只包「A500、」、蓝条包「A50指数，」、米条包「为什么会诞生」，换标题就对不上 |
| 没有干净纹理可采样 | 文字占纸条面积 **红 67% / 蓝 73% / 米 81%**，剩下都是窄边，补图接缝明显 |
| 文字本身带做旧质感 | 字里透着纸纹斑驳，是与纸张**合成**的，不是叠加图层 |

所以需要从源头出分层素材。

---

## 二、纸条素材：具体格式

### 2.1 基本要求

| 项 | 要求 | 原因 |
|---|---|---|
| 文件格式 | **PNG-24 带 Alpha 通道** | 撕边是不规则形状，必须透明背景。**不要 JPEG**（无 alpha，边缘会留白底） |
| 每条一个文件 | 红 / 蓝 / 米各一个 PNG | 程序要按行分别摆放、分别拉伸 |
| 出图角度 | **水平出图，不要预先旋转** | 旋转由程序做。已旋转的图再旋转会二次重采样，边缘发糊 |
| 投影 / 阴影 | **不要烤进 PNG**；单独出一层，或告诉我参数（偏移、模糊、不透明度） | 纸条长度会变，烤死的阴影拉伸后会失真 |
| 色彩 | 原色，不要预乘白底 | 预乘会让半透明撕边发白 |

### 2.2 关键：可拉伸结构（三段式）

标题字数每条都不同，纸条必须能**变长变短**。直接整条拉伸会把撕边和纹理拉变形，所以要拆三段：

```
┌────────┬──────────────────────┬────────┐
│ 左端帽  │      中段（可平铺）      │ 右端帽  │
│ 固定宽度 │   横向重复/拉伸都可以     │ 固定宽度 │
└────────┴──────────────────────┴────────┘
  撕边+圆角                            撕边+圆角
```

**交付方式二选一：**

**方案 A（推荐）**：每种颜色出 3 个 PNG
```
strip-red-left.png     左端帽，含左侧撕边
strip-red-mid.png      中段，宽度 200~400px 即可，左右两边要能无缝拼接
strip-red-right.png    右端帽，含右侧撕边
```

**方案 B（更省事）**：每种颜色出 1 个**超长**PNG + 一行说明
```
strip-red.png          长度按最长标题预留（建议能装 14 个中文字）
```
再告诉我：**左边多少像素是端帽、右边多少像素是端帽**（中间部分我来裁切平铺）。
例：「左端 120px、右端 120px 不可拉伸，中间随便裁」。

> 方案 B 更简单，但纹理重复会比方案 A 明显一点。先按 B 做也行，不满意再升级到 A。

### 2.3 尺寸建议

目标画布 **横版 1920×1080 / 竖版 1080×1920**。

- 纸条高度：约占画面高的 **14%~17%**（横版约 150~185px）
- 出图请按 **2 倍尺寸**（纸条高 300~370px），程序缩小使用，留清晰度余量
- 中段宽度不限，200px 以上即可

## 三、除了纸条，还需要这几样

| 素材 | 说明 |
|---|---|
| **无字底图** | 横竖各一张。就是现在的成品图**去掉纸条和文字**，只留背景拼贴（报纸、城市、电脑、放大镜等） |
| **人物抠图** | 单独一个带 Alpha 的 PNG（现在是烤在底图上的）。若人物位置固定不变，也可以留在底图里 |
| **字体文件** | 中文那个粗宋体 + 数字/字母那个衬线体，**要字体文件本身**（.otf/.ttf），或准确的字体名（我这边装） |
| **做旧纹理** | 一张灰度噪点/纸纹图（可平铺）。程序用它给文字打斑驳质感，还原「字里透纸纹」的效果 |
| **版式参数** | 见下 |

### 版式参数清单

- 每条纸条的**位置**（相对画布的百分比）和**旋转角度**
- 三行的**颜色顺序**（现在是 红 / 蓝 / 米，是否固定？）
- 文字**颜色**（每种纸条上用什么色）
- 文字**字号**（或占纸条高度的比例）
- 每行**最多几个字**；标题超长怎么办（缩小？换行？截断？）
- 标题只有 2 行或 4 行时，纸条怎么排

---

## 四、交付后我这边做什么

拿到上面这些，程序会：

1. 按标题的逗号切分成 2–3 行
2. 按每行字数算出纸条需要多长 → 端帽 + 中段平铺拼出来
3. 按给定角度旋转、按给定位置摆放
4. 用字体排字，套做旧纹理遮罩
5. 叠上人物抠图 → 输出横竖两版

**预计半天完成并出样片比对。**

## 五、如果暂时给不了分层素材

**不阻塞。** 现在的做法（每条一张 GPT 成品图，放约定目录，管线直接取用）可以一直用下去，只有两个小建议：

1. 出图尺寸直接按 **1920×1080 / 1080×1920**（现在是 1672×941 / 941×1672，我要放大 1.148 倍）
2. 文件命名与脚本标题一致，方便自动匹配

要评估的是：每期 10–15 条，GPT 那边逐条出图的**成本和风格一致性**能不能扛住。这个我判断不了。
