# 横版视频视觉规格标定

> 标定日期：2026-07-30
> 标定样本：`1782.熊市会持续多久，可以这样判断-横版.mp4`（1920×1080 / 30fps / 10.26 Mbps / 78.4s / 98MB）
> 方法：逐帧提取全分辨率画面 → 像素级测量文字 ink 边界、描边外轮廓、人脸框 → 用思源黑体反向渲染比对
> 所有数值都以**画面高度的比例**表示，与分辨率无关，可直接用于任何输出尺寸

---

## 一、输出规格

| 项 | 值 |
|---|---|
| 分辨率 | 1920×1080 |
| 帧率 | **25fps**（2026-07-30 决定：源片就是 25fps，不转换即无重复帧，文件更小、运动更干净） |
| 编码 / 容器 | H.264 / mp4 |
| 码率 | 样本为 10.26 Mbps @30fps；25fps 下取 9~10 Mbps 等效 |
| 片头 | 封面作为第 1 帧插入 |

## 二、画面裁剪与人物构图（16:9）

样本相对原始机位是**放大过的**（原片 460 期人脸占画面高 0.323，样本占 0.460 → 放大约 1.42×，裁剪框约为源画面的 70%）。

**目标（与分辨率、与期数无关）：**

| 项 | 目标值 | 实测（3 帧） |
|---|---|---|
| 人脸框高 / 画面高 | **0.460** | 0.4565 / 0.4567 / 0.4672 |
| 人脸中心 X / 画面宽 | **0.49**（≈水平居中） | 0.5239 / 0.4767 / 0.4668 |
| 人脸中心 Y / 画面高 | **0.56**（略偏下，自然留出头顶空间） | 0.5385 / 0.5771 / 0.5663 |

> 人脸框用 Vision `VNDetectFaceRectanglesRequest`，框不含头发。
> **实做：对整段每隔 1 秒检测一次，取中位数算一个固定裁剪框，全程不变**——绝不逐帧跟随，否则画面会晃。

## 三、字幕

| 项 | 值 | 说明 |
|---|---|---|
| 字体 | **思源黑体 CN（Source Han Sans CN）** | 已装，PostScript 名 `SourceHanSansCN-{Regular,Medium,Bold,Heavy,...}` |
| 字重 | **Medium**（待样片终验，见下） | 墨量占比实测：样本 0.347/0.356（阈值100/128），Medium 0.352/0.358 ✅，Bold 0.437/0.443 ❌偏重 |
| 字号 em | **133.5px @1080 高 = 画面高的 12.36%** | 用「上市公司的盈利」7 个纯中文字标定；渲染后描边外框 935×140，样本 935×141 |
| 字色 | 纯黑 `#000000` | ⚠️ 是**黑字白描边**，不是白字黑描边 |
| 描边 | 纯白 `#FFFFFF`，**外扩 10px @1080（0.93% 画面高，≈0.075 em）** | 必须是**外描边**（两遍绘制：先描边后填充），不能用 CoreText 负 strokeWidth——那会吃掉字身 |
| 描边转角 | **圆角（round join / cap）** | 样本转角是圆的；默认 miter 会出尖刺 |
| 行数 | 单行 | 流程文档要求不得两行 |
| 水平位置 | 居中（实测偏移 +3px / 0px） | |
| 垂直位置 | **描边外框底边距画面底 75px @1080 = 6.94% 画面高** | 黑字 ink 底边距 86px = 7.96% |
| 字幕带位置 | 描边外框 y = 864..1004（占 0.800~0.930 画面高） | |

**渲染实现要点**（已验证）：
```
pass 1: 白色，strokeWidth = +(2×外扩/em)×100 %，foreground = clear，lineJoin/Cap = round
pass 2: 黑色填充，同位置叠加
```

## 四、横版封面

| 项 | 值 |
|---|---|
| 背景底色 | `RGB(81,52,32)` 深棕 |
| 装饰 | 云朵形浅棕块（居中偏左）+ 右下角人物抠图（黄色描边） |
| 标题字色 | `RGB(250,244,198)` 米黄，粗黑体，**无白描边**（边缘有一层很薄的深色，待高清源文件确认是描边还是投影） |
| 标题 em | **171px @1080 = 画面高的 15.8%** | 
| 标题行 ink 高 | 145 / 147px（两行） |
| 行距 | 行 ink 顶到顶 251px ≈ **1.47 em** |
| 水平位置 | 每行各自居中（实测偏移 ±1px） |
| 垂直位置 | **整个标题块垂直居中**（两行 ink 中心 y=540.5，画面中心 540） |
| 断行 | 样本为 7 字 + 6 字，符合「每行不超过 7 字」 |

## 四·五、字幕样式定稿（2026-08-05）

**维持黑字白边。** 白字 + 黑色半透明阴影方案已实测否决——PPT 幻灯片是浅色系，白字读不出来，而含 PPT 的片子里 PPT 占比可达 86%。详见项目文档 6.11。

渲染器仍保留 `--sub-fill / --shadow-alpha / --shadow-blur / --shadow-dy` 参数，将来要试别的样式不用改代码。

## 五、仍待确认

1. **字重 Medium vs Bold**：墨量指标明确指向 Medium，但样本经过 1.42× 放大 + H.264 压缩，边缘发虚会压低墨量读数。**出第一条样片时把两个字重并排比一次即可定案。**
2. **封面高清源文件**：需要背景底图（含云朵与人物抠图）。目前只能从样本第 1 帧反推，标题文字压在云朵上无法干净还原背景。
3. **竖版字号**：流程文档横竖版都写「字号 12」，但画布不同（1920×1080 vs 1080×1920），剪映的字号单位换算不明。**需要一条竖版成品来标定**，不能从横版推。
4. 竖版「竖版标题」预设参数、竖版封面模板。

## 六、复用工具（scratchpad）

| 工具 | 用途 |
|---|---|
| `vtool info/frame/trim` | 探测、抽帧、passthrough 无损切片 |
| `measure fullframe/face/text/bright/dark/scanrow/inkarea` | 全分辨率抽帧、人脸框、亮/暗文字 bbox 与行带、像素扫线、墨量占比 |
| `crop <in> x y w h scale <out>` | 裁剪放大，用于目视比对 |
| `rendertext <文本> <字体> <em> <外描边> <out>` | 按规格渲染字幕，用于与样本比对 |
| `rms` | 音频包络与静音间隙 |
| `ASRTest.app` + `asrwin.sh` | 本地词级时间戳（用 `open -n` 启动） |
